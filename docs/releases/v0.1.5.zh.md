# dsh-hub v0.1.5 发布说明

语言：[English](v0.1.5.md) | 简体中文

状态：已收口的 release 基线。真实部署证据应保留在 operator 自己的私有仓库或运维记录中，不进入公开仓库。

v0.1.5 为受信自托管部署新增第一版多用户基线。它继续把 Authelia 作为边缘 SSO 边界，并把部署示例切换为使用 LLDAP 作为身份目录。

## 本版包含

- SQLite schema v3：Hub 用户、系统管理员、namespace 成员关系、邀请、邀请 PoW challenge、实例 ACL 元数据，以及用户/邀请审计引用。
- 基于 LLDAP 的邀请注册：
  - invite token 只显示一次，数据库只保存 peppered digest；
  - 公开邀请消费需要完成一个轻量工作量证明；
  - 公开 invite 页面和 invite API 会绕过 Authelia，其它 Portal 路径仍受保护；
  - Hub 在 LLDAP 中创建用户，区分可重试失败和需管理员 reconcile 的失败，并记录 Hub
    侧授权元数据。
- Namespace 角色：
  - `namespace_owner`；
  - `namespace_admin`；
  - `member`；
  - `viewer`。
- 轻量 Portal 管理界面：左侧导航、实例列表、namespace 列表、按角色展示的成员/邀请管理、全局审计视图、系统管理员禁用/恢复用户。
- 实例 HTTP 和 WebSocket 访问改为检查 active Hub 用户及 namespace role，不再只依赖旧的 namespace owner 字段。
- 面向 owner/admin 工作流的审计列表和实例 recover API。
- 部署模板新增 LLDAP，把 Authelia 连接到 LLDAP backend，启用 `dsh-hub-users`
  admission group gate，并让 bootstrap admin 与 LLDAP admin 用户对齐。

## 本版不包含

- 敌对租户 SaaS 级隔离。
- 自助密码重置或邮件重置密码。
- Portal 侧 hosted 模型/provider 管理。
- 自动 hosted 实例池分配。
- 生产长时压测报告、真实告警接收人或真实回滚演练。
