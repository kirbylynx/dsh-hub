# dsh-hub v0.1.0

语言：[English](v0.1.0.md) | 简体中文

v0.1.0 是 dsh-hub 的第一个 MVP 基线。它适合受信自托管评估和本地部署实验。

## 亮点

- plugin-first 的 DSH 远程访问路径。
- 独立 client 作为 fallback 和诊断工具。
- namespace、registry key、instance token、replacement grant、rotate、leave 和
  revoke 流程。
- 通过整页实例子域访问原始 DSH Web UI。
- 具备有界流控的 HTTP 和 WebSocket tunnel relay。
- Portal 安全基线：可信代理身份、Origin/CSRF 检查、CSP、ACL、分页和字段最小化。
- DSH plugin 状态卡片、本地诊断摘要、browser status endpoint、远程目录选择器
  overlay 和 `canOpenPath=false` gating。
- local 和 existing-Caddy 环境的 Docker Compose 部署模板。
- metrics、告警规则检查、恢复演练和日志/脱敏基线。

## 不包含

- 多用户角色和 namespace 共享。
- 管理后台。
- 超大会话的历史懒加载。
- 生产 release/tag 自动化。
- 托管 DSH 容器池。
- 无头自动化 API。
- 高可用、多中心或 P2P 路由。
- 面向强敌对租户的 SaaS 隔离。

## 验证

推荐的公开验证命令：

```bash
npm test
npm run deploy:m2:check
npm run deploy:m2:check:deep
npm run deploy:m2:existing-caddy:check
npm run deploy:m2:existing-caddy:check:deep
npm run deploy:m3:alerts:check
npm run deploy:m3:recovery:check
npm run deploy:m3:logging:check
```

深度部署检查需要 Docker。

## 公开仓库卫生

本 release note 有意避免真实部署域名、公网 IP、本地绝对路径、凭据和私有运维证据。
这些细节应保存在私有运维 overlay 中。
