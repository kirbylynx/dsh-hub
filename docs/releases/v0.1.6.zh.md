# dsh-hub v0.1.6 发布说明

语言：[English](v0.1.6.md) | 简体中文

状态：已收口的 release 基线。真实部署证据应保留在 operator 自己的私有仓库或运维记录中，不进入公开仓库。

v0.1.6 收口 G3：为受信自托管部署新增第一版 namespace/admin console 基线。它建立在 v0.1.5 Authelia + LLDAP 多用户基础之上，把 namespace、registry key、实例生命周期、诊断和审计操作放进 Portal 可管理范围。

## 本版包含

- 用户归属 namespace 模型：
  - namespace 是归属于 Hub 用户的实例逻辑分组；
  - 共享访问通过 namespace membership 授权；
  - 同一 owner 不能创建 normalized name 相同的 active namespace，不同 owner 可以使用同一显示名。
- Namespace 管理 API 与 Portal 流程：
  - active user 可以创建和编辑自己的 namespace；
  - system admin 可以为 active user 创建 namespace；
  - namespace 列表和详情展示稳定的 owner、membership、role、instance 和 audit 元数据，不暴露 secret digest。
- Registry key 管理：
  - 具备权限的 namespace 管理者可以展示和复制当前 namespace 入伙凭据；
  - namespace owner 可以更新当前 registry key，用于后续实例入伙；
  - registry key 更新不影响已签发的 instance token。
- 实例管理：
  - replacement grant 支持受控重新入伙；
  - revoke 和 recover 操作；
  - 按角色开放的诊断入口；
  - remote / hosted 实例的 deployment mode 展示。
- 通用管理界面改进：
  - 轻量左侧菜单 Portal 区域；
  - 可复用的列表分页组件；
  - 按角色和对象状态更清晰地展示可用操作。
- 对 namespace 编辑、registry key 展示/更新、replacement grant、实例 revoke/recover、成员/邀请变更和用户状态操作记录审计。

## 协议影响

v0.1.6 不新增 tunnel frame 类型，不改变 relay 语义。G3 是围绕既有 `proto: 1`、`minor: 1` relay 协议扩展的 HTTP/Portal 管理面能力。

## 本版不包含

- 敌对租户 SaaS 级隔离。
- Team-owned namespace 或 team administrator 角色。
- Namespace 归属转移、删除、归档或实例跨 namespace 迁移。
- 批量管理操作。
- 用户自助修改密码或管理员重置密码。
- Portal 侧 hosted 模型/provider 管理。
- 自动 hosted 实例池分配。
- 生产长时压测报告、真实告警接收人或真实回滚演练。
