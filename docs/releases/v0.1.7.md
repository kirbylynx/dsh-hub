# dsh-hub v0.1.7 release notes

Language: English | [简体中文](v0.1.7.zh.md)

Status: closed release baseline. Operator-specific deployment evidence should
stay outside this public repository.

v0.1.7 closes G15: LLDAP-backed password management for trusted self-hosted
deployments. It builds on the v0.1.5 multi-user baseline and the v0.1.6
namespace/admin console so users can change their own passwords and system
administrators can reset other users' passwords from the Portal.

## Included

- Self-service password changes:
  - active users can change their own password from `Settings -> Password`;
  - the Hub verifies the current password through LLDAP before setting the new
    password;
  - successful self-service changes return the configured logout URL so the user
    can sign in again with the new password.
- System-admin password resets:
  - system administrators can reset another Hub user's LLDAP password from the
    Users detail view;
  - every reset requires an audit reason;
  - admin reset cannot target the current administrator account.
- Shared password policy:
  - 8 to 256 characters;
  - at least one ASCII English letter and at least one digit;
  - all-whitespace passwords are rejected;
  - leading and trailing spaces are preserved rather than trimmed.
- LLDAP integration hardening:
  - the configured LLDAP bind/admin account is protected from Hub UI/API
    password changes;
  - LLDAP authentication failures are distinguished from LLDAP service
    unavailability, so outages are not reported as invalid old passwords.
- Idempotency and audit safety:
  - password writes require `Idempotency-Key`;
  - idempotent replays do not repeat LLDAP password modify operations;
  - request fingerprints use a stable service-side password idempotency HMAC
    key rather than the current token pepper;
  - idempotency records and audit details do not store raw passwords or bare
    password digests.
- Deployment templates:
  - Compose profiles now include a `PASSWORD_IDEMPOTENCY_KEY_FILE` secret;
  - README files describe how to generate and wire the additional secret.

## Protocol impact

v0.1.7 does not add tunnel frame types and does not change relay semantics.
G15 is an HTTP/Portal management-plane expansion around the existing
`proto: 1`, `minor: 1` relay protocol.

## Not included

- Email-based password recovery or forgotten-password flows.
- Email verification.
- MFA, CAPTCHA, or administrator step-up authentication.
- Password history or forced next-login password changes.
- General DSH settings or credentials bridging.
- Hostile-tenant SaaS isolation.
- Team-owned namespaces, namespace ownership transfer/deletion, bulk admin
  operations, or automatic hosted instance pool assignment.
