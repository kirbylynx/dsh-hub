# dsh-hub v0.1.5 release notes

Language: English | [简体中文](v0.1.5.zh.md)

Status: closed release baseline. Operator-specific deployment evidence should
stay outside this public repository.

v0.1.5 adds the first multi-user baseline for trusted self-hosted deployments.
It keeps Authelia as the edge SSO boundary and switches the deployment examples
to LLDAP as the identity directory.

## Included

- SQLite schema v3 for Hub users, system administrators, namespace memberships,
  invites, invite PoW challenges, instance ACL metadata, and user/invite audit
  references.
- LLDAP-backed invite registration:
  - invite tokens are generated once and stored as peppered digests;
  - public invite consumption uses a small proof-of-work challenge;
  - public invite pages and invite APIs bypass Authelia while the rest of
    Portal remains protected;
  - the Hub provisions the user in LLDAP, classifies retryable vs.
    admin-reconcile failures, and records Hub authorization metadata.
- Namespace roles:
  - `namespace_owner`;
  - `namespace_admin`;
  - `member`;
  - `viewer`.
- A lightweight Portal management UI with left navigation, instance list,
  namespace list, role-aware member/invite management, global audit view, and
  system-admin user disable/restore actions.
- Instance HTTP and WebSocket access now checks the active Hub user and namespace
  role, not only the old namespace owner field.
- Audit list and instance recover APIs for owner/admin workflows.
- Deployment templates now include LLDAP, Authelia LDAP backend wiring, the
  `dsh-hub-users` admission group gate, and a bootstrap admin aligned with the
  LLDAP admin user.
- Authelia deployment configuration is rendered through its template filter so
  the same public template can safely use environment-provided domains, LDAP
  URL, base DN, bootstrap bind user, and admission group.

## Not included

- Hostile-tenant SaaS isolation.
- Self-service password reset or email-based password reset.
- Portal-side hosted model/provider administration.
- Automatic hosted instance pool assignment.
- Production long-running load-test reports, real alert receivers, or real
  rollback drills.
